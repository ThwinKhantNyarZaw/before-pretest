# reflection.md

## When did you use Copilot?

I used GitHub Copilot throughout the development process, especially during the initial setup, while writing repetitive code structures, and when exploring unfamiliar syntax or APIs. It was particularly helpful when creating components, functions, and basic layout or logic scaffolding.

## What suggestions were useful or incorrect?

Many of Copilot’s suggestions were useful — for example, generating boilerplate code, handling fetch requests, creating default state structures, or formatting CSS classes. It saved time and reduced the amount of typing, especially for predictable patterns.

However, some suggestions were either too generic or not aligned with the specific project logic. At times, Copilot would suggest outdated methods, incomplete code, or variables that didn’t exist in my current context. These needed careful review to avoid bugs or confusion.

## How did you adapt AI assistance to meet the requirements?

I treated AI suggestions as helpful starting points rather than final answers. I reviewed and modified the code to match my project structure, naming conventions, and specific logic. In some cases, I ignored suggestions when they didn’t fit the goal or were too broad. Overall, I used Copilot to speed up routine coding, while making sure the final implementation met the actual project requirements and quality standards.
